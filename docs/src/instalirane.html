1. Как е устроена системата

marquee е един файл marquee.exe. В него са сървърът (Go) и админ интерфейсът (React), вграден при сглобяването. Не е нужна отделна база данни, уеб сървър или runtime: базата е SQLite файл в папката с данни.

Слуша наЗа какво
:8080 (всички мрежови карти)Устройствата: SMIL разписания (/p/…, /d/…) и медийни файлове (/m/…).
127.0.0.1:8081 (само тази машина)Админ панелът и неговото API.
:443 и :80Само с -domain или -cert: HTTPS за устройствата и (по избор) за админа.

Външни програми: ffmpeg и ffprobe за проверка, миниатюри, конвертиране на видео и „Видео от снимки“. Без тях системата работи, но видеата не се проверяват и не се правят видеа от снимки.

4. Сглобяване на marquee.exe

Интерфейсът се сглобява първи, защото Go вгражда готовата папка web\dist в exe-то.

cd C:\Users\<потребител>\projects\marquee

# 1. Интерфейс (първия път и при промяна на зависимостите: npm install)
cd web
npm install
npm run build          # проверка на типовете + сглобяване в web\dist
cd ..

# 2. Сървър с вградения интерфейс
go build -o marquee.exe ./cmd/marquee

Ако marquee.exe в момента работи, Windows не позволява да се презапише. Тогава сглобете под друго име и го заменете при спрян marquee (раздел 14):

go build -o marquee-new.exe ./cmd/marquee

По-малък файл и версия за Linux

go build -ldflags "-s -w" -o marquee.exe ./cmd/marquee      # без дебъг информация

$env:GOOS="linux"; $env:GOARCH="amd64"
go build -o marquee ./cmd/marquee                           # Linux сървър
Remove-Item Env:GOOS, Env:GOARCH

За Linux няма Windows услуга (използвайте systemd), а шрифтовете за текст върху снимки трябва да се сложат в tools/fonts.

5. Тестове

go vet ./...
go test ./...

# тестовете с истински ffmpeg се пропускат, ако ffmpeg не е в PATH:
$env:PATH = "$PWD\tools;$env:PATH"
go test ./... -count=1

Тестовете покриват правата и изолацията между клиенти, качване и конвертиране, видео от снимки (с истинско рендиране), кампании и одобрения до SMIL на устройството, графици (вкл. смяна на часовото време), мониторинг с тестов пощенски сървър, резервни копия, таксуване и HTTPS със самоподписан сертификат.

6. Разработка на интерфейса

За бърза работа по интерфейса без пресглобяване на exe-то:

# прозорец 1: сървърът
.\marquee.exe

# прозорец 2: интерфейсът с автоматично презареждане
cd web
npm run dev            # отваря http://localhost:5173, /api се препраща към :8081

Проверка на типовете без сглобяване: npm run typecheck.

7. Какво се копира на сървъра

C:\marquee\ ├── marquee.exe └── tools\ ├── ffmpeg.exe └── ffprobe.exe

Това е всичко. Папката data\ се създава сама при първото стартиране, до exe-то. ffmpeg може да се вземе от C:\Users\<потребител>\AppData\Local\Microsoft\WinGet\Packages\Gyan.FFmpeg.Essentials…\ffmpeg-…\bin\ или от gyan.dev. marquee търси ffmpeg в този ред: флаг -tools, папка tools\ до exe-то, PATH.

Шрифтовете за текст върху снимки се взимат от C:\Windows\Fonts (Arial, Segoe UI, Impact, Verdana, Georgia, Comic Sans). Ако липсват, сложете ги в tools\fonts\.

8. Първо стартиране

  1. Създайте супер админ (само първия път). Паролата се пита два пъти и не се вижда; поне 10 символа. 
    .\marquee.exe create-super -email ti@firma.bg -name "Георги"
  2. Пуснете хъба: 
    .\marquee.exe
    В конзолата (и в data\logs) се вижда къде слуша и адресът за устройствата.
  3. Отворете админа на http://127.0.0.1:8081 и влезте.
  4. Настройки → Адрес на хъба: въведете статичния публичен IP, ако устройствата са извън локалната мрежа.
  5. Спиране: Ctrl+C в прозореца.

Програмата приема само флагове. Дума без тире (напр. marquee.exe serve) спира старта с грешка, за да не се пренебрегнат тихо следващите флагове.

9. Команди

КомандаКакво прави
marquee.exe [флагове]Стартира хъба (раздел 10 за флаговете).
marquee.exe -hСписък на флаговете.
marquee.exe create-super -email … [-name …] [-data …]Създава супер админ. Може да се пусне и докато хъбът работи.
marquee.exe install-service [флагове]Инсталира и стартира Windows услуга с тези флагове (раздел 12). Като администратор.

Паролата за create-super може да се подаде и през pipe (напр. при автоматизация): "парола-от-поне-10" | .\marquee.exe create-super -email ti@firma.bg.

11. Мрежа: портове, рутер, защитна стена

Устройствата трябва да стигат до порт 8080 (TCP) на машината.

  • Устройства в същата локална мрежа: адресът е IP-то на машината (напр. http://192.168.1.20:8080). Нужно е само правило в защитната стена.
  • Устройства на други обекти по интернет: на рутера пренасочете външен порт 8080 (TCP) към вътрешния IP на машината, порт 8080. В Настройки → Адрес на хъба въведете статичния публичен IP.
  • Машината трябва да има постоянен вътрешен IP (резервиран в рутера или статичен), иначе пренасочването спира да работи.

Защитна стена на Windows

install-service добавя правило автоматично. При ръчно пускане Windows пита при първото стартиране (натиснете „Разреши“), или добавете правило ръчно като администратор:

New-NetFirewallRule -DisplayName "marquee" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow

Проверка

От друг компютър или телефон отворете http://<IP>:8080/p/pair.html. Отговор „404“ означава, че хъбът се достига (страницата е само за устройства). Ако няма отговор, проблемът е в мрежата.

Админ панелът (:8081) е достъпен само от самата машина. Това е нарочно: без HTTPS паролата би минавала некриптирано. За достъп отвън вижте раздел 13.

12. Работа като Windows услуга

Като услуга marquee тръгва автоматично с Windows (без да се влиза в профил), рестартира се сам при срив (до 3 пъти на ден, през 10 сек) и пише лога в data\logs.

# PowerShell като администратор, в папката на exe-то
.\marquee.exe install-service                                  # с настройките по подразбиране
.\marquee.exe install-service -refresh 10m -data D:\marquee-data  # със свои флагове

Get-Service marquee           # състояние
Stop-Service marquee
Start-Service marquee
Restart-Service marquee

.\marquee.exe uninstall-service   # махане; данните остават
  • Пътищата във флаговете трябва да са пълни (D:\…), защото услугата стартира в C:\Windows\System32.
  • За смяна на флаговете: uninstall-service, после install-service с новите.
  • Услугата работи като LocalSystem. Мрежова папка за резервни копия трябва да е с пълен UNC път (\\сървър\папка) и достъпна за компютърния акаунт; мапнатите букви (Z:) не се виждат от услугата.
  • Инсталирането като услуга още не е изпробвано на живо: проверете с Get-Service marquee и логовете.

13. HTTPS и достъп до админа отвън

Без домейн системата работи по HTTP на IP: устройствата се свързват, а админът е само локален. HTTPS е нужен, ако искате админ панела отвън.

С домейн и Let's Encrypt (безплатно, автоматично)

  1. Домейн, насочен към публичния IP. Подходящ е и безплатен (напр. DuckDNS).
  2. Пренасочени портове 80 и 443 на рутера към машината, правила в защитната стена.
  3. Пускане: 
    .\marquee.exe -domain ads.firma.bg -acme-email ti@firma.bg -public-admin

Сертификатът се взима при първата HTTPS заявка и се подновява сам; пази се в data\certs. Android 7.1.1 приема сертификатите на Let's Encrypt. С -public-admin логин страницата е на https://ads.firma.bg/. Без него отвън се виждат само екраните. Устройствата могат да ползват и http://, и https:// адреси.

Със собствен сертификат

.\marquee.exe -cert C:\certs\hub.pem -key C:\certs\hub-key.pem -public-admin

Let's Encrypt не издава сертификати за голи IP адреси, затова HTTPS изисква домейн или собствен сертификат.

14. Обновяване до нова версия

При ръчно пускане

# 1. сглобете новата версия под друго име (старата може да работи)
go build -o marquee-new.exe ./cmd/marquee

# 2. спрете marquee (Ctrl+C), заменете и пуснете отново
Move-Item -Force marquee-new.exe marquee.exe
.\marquee.exe

При услуга

Stop-Service marquee
Move-Item -Force marquee-new.exe marquee.exe
Start-Service marquee

След обновяване натиснете Ctrl+F5 в браузъра, за да се зареди новият интерфейс. Промените по базата (миграции) се прилагат автоматично при старт. Препоръчително е преди обновяване да направите копие от Настройки → Направи копие сега.

15. Папката с данни

data\ ├── marquee.db базата: клиенти, потребители, устройства, кампании, настройки ├── marquee.db-wal, -shm временни файлове на базата (не се трият ръчно, докато работи) ├── media\ │ ├── ab\abcd….jpg качените файлове, именувани по съдържанието си │ ├── thumbs\ миниатюри │ └── tmp\ временни файлове при качване и обработка ├── logs\ marquee-ГГГГ-ММ-ДД.log, по един на ден, 90 дни ├── backups\ резервни копия (ако не е избрана друга папка) └── certs\ HTTPS сертификати (само с -domain)

Цялото състояние на системата е в тази папка. Рестартът на машината или програмата не губи нищо.

16. Резервни копия и възстановяване

Автоматично всяка нощ (по подразбиране 03:00), настройва се в Настройки. Всяко копие е marquee-ГГГГММДД-ЧЧММСС.db плюс папка media с всички файлове. Копието на базата се прави без спиране на хъба.

Възстановяване

  1. Спрете marquee (Ctrl+C или Stop-Service marquee).
  2. Преименувайте текущата data\marquee.db (за всеки случай) и изтрийте marquee.db-wal и marquee.db-shm.
  3. Копирайте избраното marquee-….db като data\marquee.db.
  4. Копирайте папката media от копието върху data\media (липсващите файлове).
  5. Пуснете marquee.

Преместване на друга машина

Копирайте marquee.exe, tools\ и цялата папка data\ (при спрян marquee). На новата машина сменете адреса на хъба в Настройки, ако IP-то е друго. При личните линкове смяната на IP изисква нов адрес на устройствата.

17. Логове

Файлове data\logs\marquee-ГГГГ-ММ-ДД.log, четими с Notepad, или в админа: меню Логове. Формат:

2026-11-10 15:36:37  ИНФО      Слуша за устройства                      адрес=:8080
2026-11-10 15:36:37  ИНФО      Адрес за устройствата                    адрес=http://85.10.20.30:8080
2026-11-10 15:35:41  ИНФО      Ново устройство чака свързване           код=STZB2B име=Vitrina ip=10.0.0.15
2026-11-10 15:35:42  ВНИМАНИЕ  Неуспешен вход                           имейл=nobody@x.bg ip=127.0.0.1

Нива: ИНФО (нормални събития), ВНИМАНИЕ (нещо за проверка), ГРЕШКА (нещо не е станало). При ръчно пускане същите редове се виждат и в конзолата.

18. Отстраняване на проблеми

The process cannot access the file при сглобяванеmarquee.exe работи. Сглобете като marquee-new.exe (раздел 14).
„Няма ffmpeg“ в логаСложете ffmpeg.exe и ffprobe.exe в tools\ до exe-то или задайте -tools.
Адресът за устройствата е вътрешенВъведете публичния IP в Настройки → Адрес на хъба. Пренасочете порт 8080 на рутера.
Новият интерфейс не се виждаCtrl+F5 в браузъра. Проверете, че е пуснат новият exe (бил ли е спрян старият).
